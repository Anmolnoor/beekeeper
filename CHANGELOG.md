## [0.1.0] - 2026-04-30

### Added

- Initial public release.
- Queen orchestrator with tool-level policy enforcement.
- Ephemeral workers: `web_search`, `heavy_compute`, `audit`, `forged`.
- Honeycomb event log with append-only trace/replay.
- Tool registry with PII guardrails, domain allowlists, and HITL gates.
- Dual execution modes: `legacy_worker`, `model_tools`, `hybrid`.
- MCP adapter (stdio + HTTP) for external tool servers.
- LLM provider abstraction with Ollama / Gemini / OpenAI fallbacks.
- Per-user policy with `deny` / `ask` / `allow` actions and HITL review queue.
- Beekeeper API (port 8787) and Queen API (port 8788).
- CLI: `beekeeper`, `beekeeper chat`, `beekeeper run`, `beekeeper doctor`,
  `beekeeper quickstart`.
- Docker Compose stack (Postgres, Redis, Temporal, Qdrant, SearXNG, Ollama).
- Apache 2.0 license.
- Pi-mono-style contribution gate (auto-close from non-allowlisted contributors).
